/* ============================================================
   笔记块 · 紧凑块（让块与块、列表项之间贴紧）
   ------------------------------------------------------------
   用途：解决“能不能不写空行、让笔记更紧凑”。
   结论：Markdown 语法要求相邻标注块之间必须有空行，否则会被解析成
        同一个块 —— 这一点 CSS 改不了。但可以用本片段把块间**间距**
        压掉：源码里照写空行，视觉上却是紧贴的一叠卡片。

   效果：
     1) 相邻两个块直接贴住（后块与前块之间间距 0，衔接处圆角收平）；
     2) 块内段落、列表项间距收紧。
   只作用于标注块相邻关系与块内内容，
   孤立块、块后接正文的情形不受影响。
   不想要紧凑效果时，把本片段的开关关掉即可。
   ============================================================ */

/* ============================================================
   一、相邻块“贴住”
   ============================================================ */

/* 全局兜底：把默认的 1.15em 块间留白压到 0.5em。
   这一条在「阅读视图」和「实时预览」两种模式下都生效。 */
.callout {
  margin-block: 0.5em;
}

/* 阅读视图下相邻两块可以完全贴住：
   只有“块紧挨着块”时才压成 0，中间夹着正文的块不受影响 */
.callout + .callout {
  margin-top: 0;
}

.callout:has(+ .callout) {
  margin-bottom: 0;
}

/* 衔接处收圆角 + 收阴影，看起来像一叠卡片而不是两个独立卡片 */
.callout:has(+ .callout) {
  border-bottom-left-radius: 4px;
  border-bottom-right-radius: 4px;
  box-shadow: none;
}

.callout + .callout {
  border-top-left-radius: 4px;
  border-top-right-radius: 4px;
}

/* 说明：全局兜底那条一定生效；下面几条相邻规则让贴得更彻底，
   在阅读视图生效，在实时预览里可能匹配不到（不改也不出错）。 */

/* ============================================================
   二、块内更紧凑
   ============================================================ */

.callout .callout-content {
  line-height: 1.75;
}

.callout .callout-content > p {
  margin: 0.35em 0;
}

/* 块内列表：项与项、列表与上下文之间都收紧 */
.callout .callout-content ul,
.callout .callout-content ol {
  margin: 0.35em 0;
  padding-inline-start: 1.4em;
}

.callout .callout-content li {
  margin: 0.15em 0;
}

.callout .callout-content li > p {
  margin: 0.2em 0;
}

.callout .callout-content li > ul,
.callout .callout-content li > ol {
  margin: 0.15em 0;
}

/* 块标题与正文之间少留一点 */
.callout > .callout-title {
  margin-bottom: 6px;
  padding-bottom: 4px;
}
