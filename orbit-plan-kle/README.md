# Orbit Plan

一个视图里上下两块：**上半是旋臂星图，下半是每周四项计划表**（含 PDCA 复盘）。以**标签页**打开（和 Obsidian 自带的「关系图谱」一样），中间那条分隔线可以拖着改比例。

## 上半：旋臂星图

- 中心 = 双链连接最多的那篇笔记；
- 其余 Markdown 按 `creation-time` 升序**顺序填轨**：每轨容量 = `2·(π/e)^(3n)`（第 1 轨 3 个、第 2 轨 4 个、第 3 轨 7 个…，PDF 不占容量）；
- **三颗彗星**：第 1 轨（`e = 0.8`）、最外轨（`e = 0.618`）各一颗，外加**一个 PDF**；椭圆长轴绕焦点缓慢进动（约 105 秒一圈），球在椭圆上按开普勒快慢运动；
- **PDF 彗星**按「文件名最后一个词的拼音首字母」取最大的那个 PDF；`e = 0.45`、速度 1.2 倍、保留漂移，近点仍在最外 MD 轨之外；它**撞到**的笔记球会临时降一个轨道（3 秒冷却，重建时按抖动重新定轨）；
- **时钟**：PDF ≥ 5 时，除两颗彗星外的第 3~5 个 PDF 变成时/分/秒针（球体 19.2 半径（PDF 的 6 倍）、球内显示 24 小时制的时、分、秒，数字用 Times New Roman 并随缩放变化、颜色取中心球，角度严格按系统时间；三针半径 0.68 / 0.81 / 0.92 倍 PDF 环，模拟表盘长短）；
- **平时不显示名称、也不画连线**：鼠标悬停到某个节点才显示它的名称、高亮环、以及它自己的双链连线，并**只冻结这一个节点**（移开后约 0.5 秒平滑归位）；
- 颜色**由外向内**渐变（外圈最浅、中心最深），也可以右键给单个节点单独定色；
- **球体可以拖**：按住非彗星球拖动，松手后自动吸附到最近的一条轨道（角度保持不动，方向跟随目标轨道，也不影响彗星选取）；彗星不可拖；吸附结果可一键清除；
- **球间斥力**可调（0–1，默认 0.35）：挨太近的球会被轻轻推开，彗星与普通球一视同仁，单帧位移有封顶；**同一轨道挤太近时会把其中一颗抬到外一圈**（判定：同轨中心距 ≤ 两球半径和 × 2；瞬时、无冷却、每帧最多抬一轨）；
- **连接越多球越大**：2.6 + √连接数 × 2.4（封顶 10），中心球始终最大一点；
- PDF 在最外圈慢速公转 + 范围内缓慢无规则漂移（半径 −11%~+5%、角度 ±7%），并对相连笔记轻微吸引；
- **没有标签层**。

## 下半：每周四项计划表

数据就是仓库里的每周笔记：`orbit-plan/<年>/<周>周.md`（目录可在设置里改，周号两位补零）。

```markdown
# 2026 年第 43 周 · 10月19日 – 10月25日

## 重要 · 紧急
- [ ] 交房租
- [x] 写周报

## 不重要 · 紧急
## 重要 · 不紧急
## 不重要 · 不紧急

## PDCA 复盘
### P 计划（Plan）
### D 执行（Do）
### C 检查（Check）
### A 改进（Act）
```

- 四个象限在面板里勾选 / 新增 / 删除，改动**只写那一行**（`vault.process` 原子写，定位失败就放弃并提示，不会重排整篇）；
- 新增任务时**回车即提交并在同一象限继续输入**，可连续敲多条；`Esc` 或空内容失焦才收起；
- 象限下方有一条**胶囊完成度进度条**：本周「已完成 / 总数」的百分比（没有任务时显示 0%）；
- 抬头（`2026 年第 43 周 · 10月19日 – 10月25日`）用中文楷体 + 英文 Times New Roman，字色 `#6D4D99`；
- 「本周 / 上一周 / 下一周」切换；**点击周次**可跳到任意年 / 周；
- 「导入上周未完成」把上一周所有 `- [ ]` 追加到本周对应象限（按文本去重）；
- **PDCA 复盘**默认折叠，点开后点击任意一节即可就地编辑，写回对应小节；
- 空周不落盘：只有真的新增 / 修改时才创建文件夹与笔记。


界面全中文，仅桌面端。插件 id：`orbit-plan-kle`。

## 安装（工作区里的实验仓库已装好）

工作区的 `.obsidian/plugins/orbit-plan-kle/` 已经放了 `manifest.json`、`main.js`、`styles.css`，
`.obsidian/community-plugins.json` 里也已启用（与原有的 `orbit-graph-view` 并存）。

装到别的仓库：

1. 把 `orbit-plan-kle` 整个文件夹拷到 `<仓库>/.obsidian/plugins/`（这三个文件必须有）。
2. 设置 → **第三方插件** → 打开社区插件 → 启用 **Orbit Plan**。
3. 点左侧功能区的原子图标，或命令面板执行「打开关系图谱视图」。

改完代码后的迭代方式：

```bash
cd orbit-plan-kle
node build.mjs                                            # 生成 main.js
copy main.js <仓库>/.obsidian/plugins/orbit-plan-kle/      # 覆盖安装
```

在 Obsidian 里用命令 **Reload app without saving**（或关掉插件再打开）即可看到新版本。

## 打开方式与操作

打开方式与 Obsidian 自带的「关系图谱」一致：**在主编辑区开一个标签页**。

| 操作 | 效果 |
|---|---|
| 点侧边栏图标 / 运行命令 | 已经有图谱标签就**跳过去聚焦**，没有才新建 —— 不会越点越多 |
| 关闭 | 用标签页原生的 ✕ |
| 拖标签 | 可以拖到左右分栏、或拖出来成为独立窗口（Obsidian 自带能力） |
| 光标在节点上 | 显示名称 + 高亮环 + 该节点的双链连线，并冻结这个节点 |
| 左键点节点 | 打开该文件（按类型复用同类标签页） |
| 右键点节点 | 单独取色 |
| 滚轮 / 拖拽画布 | 缩放 / 平移图形 |
| 空格 | 暂停自转（该标签是当前激活视图时生效） |

打开的图谱标签与其它标签一样会被 `workspace.json` 记住，**重启 Obsidian 会自动恢复**。

> 它就是一个真正的视图：可拖动、可分屏、可关闭，和自带的关系图谱平级。

## 布局规则

| 项 | 规则 |
|---|---|
| 中心笔记 | md 中双链连接数最多者；并列取 `creation-time` 更早的，再并列取路径字典序。**PDF 不参与** |
| 半径 | 只由 `creation-time` 决定：越早创建越靠内（双链跳数**不**参与半径） |
| 轨道容量 | `2·(π/e)^(3n)` 向下取整：3 / 4 / 7 / 11 / 17 / 27 …；PDF 不占容量 |
| 轨道速度 | 内环按轨道线性：最内 1× → 最外 1.5×（轨道越大越快，彗星除外） |
| PDF 速度 | 按文件大小线性：最小 1.5× → 最大 1×（基准 0.28×，时钟针与彗星除外） |
| 轨道方向 | **第 1、2 轨顺时针**，第 3 轨起**逆时针**（PDF 保持原方向） |
| 抖动 | 每个球建图时掷一次确定性骰子：**10% 向外一轨、11% 向内一轨、79% 不动**（按路径哈希，不随帧变化） |
| 轨道溢出 | 某轨超容量时，把该轨里 title 比较「最大」的球挪到**最近的有空位轨道**（优先向外） |
| **彗星轨道** | 只在第 1 轨与最外轨各一个（轨道数不足 2 条则不生成）。挑人：`title`（缺失用文件名），先比首字符、相同再从最后一个字符往前比，最后比整串与路径。第 1 轨 `e = 0.8`（长半轴会抬高，保证近点不贴中心球），最外轨 `e = 0.618`。焦点在中心，用偏近点角解 `M = E − e·sinE` 实现近点快、远点慢 |
| PDF | 最外圈（半径取「最外轨道」与「所有彗星远点」的较大者再加间距，保证永远在最外层）；角速度 0.28 倍；叠加缓慢无规则漂移 |
| 创建时间 | 优先 frontmatter 的 `creation-time`，缺失时回退文件系统创建时间 |

`creation-time` 支持：`2024-03-05`、`2024/3/5`、`2024-03-05 14:30`、ISO 串、`Date`、秒级/毫秒级时间戳。

## 颜色与名称

- **色系**：粉紫 → 深紫（#EBCFE4 → #CE9BC7 → #9B62A8 → #4E2A66）/ 浅红 → 玫红（#F7D9D9 → #D88090 → #DD4E70）。按半径归一化取色，方向**由外向内**：外圈取首色（最浅），中心取末色（最深）。
- **单节点颜色**：右键取色，按文件路径记在 `data.json`，重命名时自动迁移。
- **名称**：默认不显示；悬停哪个节点就只显示哪个。

## 设置项（全中文）

| 设置 | 说明 |
|---|---|
| 色系 | 两套渐变配色（粉紫 → 深紫 / 浅红 → 玫红） |
| 层间距 | 最外圈半径：越大球摆得越开 |
| 自转速度 | 整体转速（PDF 层 0.28 倍跟随）；0 即静止 |
| 轨迹长度 | 尾迹长度；**普通节点与彗星都受它控制**，0 关闭 |
| 节点大小 | 所有球体统一缩放，屏幕最小 2.2px |
| 球间斥力 | 0–1，越大越把挨近的球推开；彗星与普通球同等参与 |
| 轨道吸附 | 显示被拖拽吸附的球数，可一键清除 |
| 自定义颜色 | 显示单独设色的节点数，可一键清除 |
| 计划笔记位置 | 每周笔记的根目录，默认 `orbit-plan`（按「目录/年/周.md」存放） |
| 上下比例 | 上半星图占视图高度的比例（也能直接拖动中间的分隔条） |

## 离线预览（不开 Obsidian 也能看形状）

```bash
node build.mjs
node dev/preview.mjs 20 7.5          # 参数：笔记数、时钟秒数
python dev/render_preview.py          # 生成 dev/preview.png
```

`dev/preview.mjs` 调用 `main.js` 里同一份 `GraphBuilder / Layout / pose / attraction`，所以预览与插件是同一套坐标。

## 构建与自测

零依赖，`main.js` 由源码模块拼接：

```bash
node build.mjs
node dev/test.mjs      # 100 项断言
```

| 源文件 | 职责 |
|---|---|
| `src/core.js` | 数学、拼音/尾部排序、颜色工具、全部中文文案 |
| `src/palette.js` | 两套色系与由外向内的半径取色 |
| `src/graph.js` | 建图：md + pdf、标题、创建时间、中心选举 |
| `src/layout.js` | 轨道容量与填轨、抖动与溢出、方向、位置计算（pose、彗星开普勒、PDF 漂移）+ PDF 有界吸引 |
| `src/plan.js` | 每周计划的纯逻辑：ISO 周、笔记路径、解析、单行增删改、导入合并 |
| `src/renderer.js` | Canvas 2D：点、尾迹、悬停连线与名称 |
| `src/view.js` | 视图（ItemView）：上下分区、星图动画、计划面板、取色弹窗、跳周弹窗 |
| `src/plugin.js` | 插件入口：注册视图、聚焦优先的打开逻辑、中文设置页 |

## 已知限制

- **我无法在 Obsidian 里亲眼验证**：验证做到「构建通过 + 100 项断言（含假 DOM 的渲染链、打开逻辑、广播、计划面板）+ 离线出图」为止。真机手感请点一下反馈。
- 多开几个图谱标签会各跑一份动画循环（节点上千时叠加才明显）。
- 仅桌面端（`isDesktopOnly: true`）。
- 节点只有 3~5 篇时看不出螺旋，彗星也要 ≥ 2 条轨道（约 6 篇以上）才会出现。
- 空格暂停只在该标签为激活视图时生效。
