# 笔记块 · 数学块（公众号版）

这篇笔记是 **WeChat Converter 插件「自定义 CSS」的样式来源**，只服务公众号链路：普通预览 / 复制到公众号 / 同步微信公众号草稿。

- Obsidian 阅读视图用的原件是 `.obsidian/snippets/笔记块-数学块.css`，本文件是它的公众号移植版，视觉目标一致：**定义紫 · 定理蓝 · 命题青 · 引理蓝绿 · 推论靛 · 公式紫罗兰 · 记号石板灰 · 例题（浅灰底 + 红色标签靠右）· 证明（素净段落 + 末尾 ∎）**。
- 下面这个 `css` 代码块是插件真正读取的内容（代码块之外的说明文字会被忽略）。
- 移植对照原件，只有 7 处差异（其余选择器、配色、间距与原片段逐条对应）：

| # | 原件写法 | 这里写法 | 原因 |
|---|---|---|---|
| 1 | `.callout[data-callout="定理"]` | `.owc-callout[data-callout="定理"]` | 插件导出的是自己的 `.owc-callout` 结构；类型由插件写进 `data-callout`（英文小写、中文原样） |
| 2 | `.callout:lang(定义)` | `[data-callout="定义"]` | 插件直接把中文类型写进属性，不需要 `:lang()` |
| 3 | 普通声明 | 每条都带 `!important` | 插件把主题样式内联在元素的 `style` 上，不加压不住 |
| 4 | `--callout-color` 变量 | 字面色值 | 内联引擎解析不了 CSS 变量，值会丢 |
| 5 | `--callout-icon: lucide-*` | 删掉（插件用 emoji 图标） | emoji 是字形颜色，CSS 改不动；插件已按类型配了 emoji |
| 6 | — | 正文区 `padding/background` 归零 + 每类型补一条标题 `span` 颜色 | 插件给正文区自带内边距和底色；标题颜色写在子 `span` 上 |
| 7 | `mjx-container` | `[data-owc-math]` | 插件把公式转成 `section/span + SVG` |

- 依赖：需要插件把 Callout 类型写进导出 HTML（本机已打补丁：`converter.js` 输出 `class="owc-callout" data-callout="类型"`，序列化器保留这两个钩子）。**插件升级会覆盖补丁**，届时重新应用一次即可（补丁说明见插件目录 `.dsh-backup/PATCH-NOTES.md`）。
